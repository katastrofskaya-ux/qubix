# qubix

Рабочее пространство роста и стратегии Qubix (испытательный срок Анастасии
Войтенко, 27.07.2026–26.10.2026).

- **`CLAUDE.md`** — читать первым: полный контекст (роль, KPI, позиционирование,
  каналы, риски) для любой новой сессии.
- **`TASKS.md`** — живой чек-лист задач на 2 месяца, единственное место, где
  фиксируется прогресс.
- **`docs/`** — база знаний по темам (договор, конкуренты, тон, медиа-карта,
  sales-плейбук, воронка, календарь конференций).
- **`.claude/agents/qubix-growth-lead.md`** — специализированный агент для
  стратегии/ведения проекта, привязанный к этому контексту.
