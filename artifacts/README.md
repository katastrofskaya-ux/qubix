# Артефакты — исходники живых страниц

Здесь лежат исходники страниц, опубликованных инструментом Artifact, чтобы их
можно было править и перевыпускать, а не собирать заново.

| Файл | Страница | Что это |
|---|---|---|
| `marshrut.html` | claude.ai/artifact/7CSVH3NkmDXGacB9W5Usa6 | Карта движения по задачам: пять этажей от большего к меньшему, галочки сохраняются |
| `lissabon.html` | claude.ai/artifact/9QFPUuZqBg5r3V7r7wHtXr | Поездка на SBC: код и QR, шкала приоритетов, таблицы участников, сайд-ивенты, тексты касаний |

Перевыпуск — инструментом Artifact по тому же URL. Галочки на карте движения
живут в базе страницы и правкой исходника не затрагиваются.
