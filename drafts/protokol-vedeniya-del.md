# Протокол ведения дел — v3

Собран 28.09 по переписке с владельцем 17–26.09 (248 его замечаний), по BRAND-9 v2 и BRAND-12, с четырьмя критиками: ревизор, психолог, бизнесмен, маркетолог. Всё, что помечено «предложение», — моё и ждёт решения. Цитаты владельца — дословно, с датой.

## 0. Зачем

Одна цель — **платящие клиенты по цене не выше потолка**. Всё остальное (тексты, каталоги, закупка, конференции) — средство, и меряется тем, сколько платящих дало и почём.

Почему v2 не сработала: она вела от темы к размещению, а не к платящему. Прогноза до оплаты не было. Тормоза по деньгам не было. Функции продаж не было. Решения жили в Telegram. 26.09 владелец закрыл закупку «в лоб» — механизм v2 стоит на отменённом основании.

## 1. Пять правил, из которых следует всё остальное

1. **Решаем по числам.** Прогноз до траты, замер после, одна мера на все месяцы. «Решения принимаются по метрикам, не сферического коня в ваккуме» (22.09).
2. **Всё — в Ю-треке.** Вопрос, аппрув, объяснение, протокол. В Telegram — ссылка на задачу и одна строка. «Для всех вопросов — конечно таска в ютреке. И для порядка и для протокола. Не тг» (18.09).
3. **Приходить с вопросом до работы и с решением после.** Не с готовым текстом на «как тебе», не с проблемой на «как быть». «Всегда — просто сразу дока на аппрув» (18.09); «ты пришла ко мне с прогибом и пихаешь мне на аппрув» (22.09).
4. **Своя зона — делаю сама.** Переговоры, условия, давление на подрядчика — моё. «Д — дипломатия, это то, зачем ты взята… Это твоя часть» (22.09); «мне нужен готовый специалист» (22.09).
5. **У каждого факта — источник.** Устного без протокола не существует. «Покажи где я это сказал?» (26.09).

## 3. Деньги: четыре шага

1. **Карточка прогноза в задаче траты — до оплаты.** Канал · сумма · код · дата выхода · дата замера · прогноз (регистрации, серверы, платящие, цена платящего) · что подрядчик делает при недоборе. Без карточки оплаты нет.
2. **Потолок.** Цена платящего не выше **~$1 200** — потолок компании по полному CAC (MARKETING-38; admin, BRAND-12, 22.09). Для канала — пересчёт на ступени по факту воронки (предложение: считать раз в месяц).
3. **Стоп-правила** (предложение, числа — на утверждение владельцу):
   - **С1 — новый канал:** первый платёж не больше $1 000, следующий — только после замера.
   - **С2 — портфель:** потрачено с последнего нового платящего больше двух потолков ($2 400) → все траты с фиксированной ценой на стоп до решения владельца в задаче.
   - **С3 — подрядчик:** блогерам только CPA, «Без всяких предоплат. Оплату только по факту оплат нам» (26.09); остальным предоплата не больше половины.
   - **С4 — порог задним числом не двигается.** Пересмотр — новой карточкой, до следующей траты.
4. **Отчёт** — раз в неделю, одной формой (раздел 4).

## 5. Как говорю с владельцем

- **Ответ на замечание — три шага.** Понимание: «Поняла так: …» → подтверждение: «Верно?» → действие: «Делаю …, в задаче N до …». Одно сообщение, а не двадцать.
- **Ошибка:** что именно → последствие → исправление с датой → правило, чтобы не повторилось. Без «я просто», «я не умею», «ты же сказал».
- **Спор — только числом в задаче.** «Вижу другую цифру: X против Y, разница из-за …». Если вывод от этого не меняется — сказать сразу.
- **Первая волна** (сильные слова, ночь, дорога) — одна строка «Прочитала, отвечу в задаче до 12» и ответ по сути в рабочее время.
- **Его личное** — один вопрос одной строкой, без спора.
- **Своя позиция** — один раз и держаться. Он сам оставил выбор: «Ты можешь действовать как хочешь» (22.09).
