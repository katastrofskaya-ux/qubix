**Продажи по каналам: деньги и сравнение площадок**

**Зачем.** Владелец просит эффективность на каждый вложенный доллар: цена регистрации, лицензии, инсталла по каждой площадке. В «Продажах по каналам» воронка по кодам есть, а денег нет — сейчас это сводится руками из ведомости, и цифры расходятся с админкой.

**Что нужно**

1. **Расход на код.** Поле «потрачено, $» и дата выхода размещения; можно несколько записей на один код (один канал покупали дважды).
2. **Цена каждой ступени.** Колонки $ за регистрацию, $ за лицензию, $ за первый сигнал продукта, $ за платящего — расход ÷ число на ступени.
3. **Площадка.** Объединить коды одной площадки в одну строку (ADHUNT + ADHUNT1, CPAGRAM + CPAGRAM1, AFFINSIDE + AFF_INSIDE, IGAMINGNEWS + IGAMING_NEWS).
4. **Тип канала — тег.** Пост в Telegram, листинг, блогер, Google, конференция. Сводка по типу: блогеры с блогерами, листинги с листингами.
5. **Период.** Счёт за выбранный месяц и за N дней после даты выхода.
6. **Свои аккаунты.** Пометить клиента как «свой / контрагент» (как сейчас internal) — сейчас по кодам стоят сами площадки и наши сотрудники, их приходится вычитать руками.
7. **Выгрузка в CSV.**

**Готово, когда** по любой площадке за сентябрь из админки видно: потрачено, регистрации, лицензии, инсталлы, оплаты и цена каждой ступени — без ручного сведения.
