**Цена ступени по каналам: вопросы перед постановкой**

Хочу видеть по каждой площадке и типу канала: потрачено → регистрации → лицензии → первый сигнал → платящие и цену каждой ступени. Прежде чем ставить задачу, нужно понять, как это сделать без лишней работы для вас.

1. «Продажи по каналам» уже считают воронку по коду. Можно ли хранить рядом с кодом сумму расхода и дату выхода размещения — или расход в этой базе держать нельзя? Если нельзя — где его держать, чтобы админка могла поделить?
2. Строка Google в «Продажах по каналам» берёт расход сама? Можно ли так же подтягивать расход по остальным каналам — например, из задачи оплаты?
3. У промокода есть поле partner_id. Можно ли через него (или новым полем «площадка») складывать коды одной площадки в одну строку — ADHUNT + ADHUNT1 и т. п.?
4. Можно ли повесить на код тег типа канала (пост TG, листинг, блогер, Google, отдел продаж, конференция) и дать итог по типу?
5. Отметку internal на клиенте ставит только разработка или её можно ставить из админки? Нужна ещё одна причина — «контрагент»: сами площадки и наши сотрудники, которые регистрировались по своим кодам.
6. Можно ли считать воронку не за весь срок, а за N дней от даты выхода размещения?
7. Если ничего из этого сейчас не делаем — можно ли выгрузку «Продаж по каналам» в CSV по коду и дате регистрации, без своих и тестовых? Тогда посчитаю сама, но из ваших данных, а не руками из ведомости.
