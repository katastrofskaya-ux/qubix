**Цена ступени по каналам: вопросы перед постановкой**

Хочу видеть в «Продажах по каналам» по каждой площадке и типу канала: потрачено → регистрации → лицензии → первый сигнал → платящие и цену каждой ступени. Период, отбор технических и выгрузка там уже есть — не хватает четырёх вещей. Прежде чем ставить задачу, нужно понять, как их сделать без лишней работы для вас.

1. **Расход.** Можно ли хранить рядом с кодом сумму расхода и дату выхода размещения (несколько записей на код) и считать $ за каждую ступень? Если в этой базе расход держать нельзя — где его держать, чтобы страница могла поделить? Для Google расход уже есть в статистике рекламы — можно ли подтянуть его в строку Google?
2. **Площадка.** Можно ли объединять коды одной площадки в одну строку (ADHUNT + ADHUNT1, CPAGRAM + CPAGRAM1, AFFINSIDE + AFF_INSIDE, IGAMINGNEWS + IGAMING_NEWS) — через partner_id у промокода или новым полем? Сейчас «Канал» выбирает только один код, а коды без регистраций (например SBC_LISBON) в этот список не попадают вовсе — их видно только в своде.
3. **Контрагенты.** «Технический» сейчас — только наши прогоны. Можно ли отмечать так же клиентов-контрагентов (площадка или блогер, зарегистрированные по своему коду, наши сотрудники) — и кто ставит отметку?
4. **Тип канала.** Можно ли повесить на код тег (пост TG, листинг, блогер, Google, отдел продаж, конференция) и дать итог по типу?
