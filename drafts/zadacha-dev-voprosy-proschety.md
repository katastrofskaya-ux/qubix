**Продажи по каналам: цена ступени по площадкам — вопросы перед постановкой**

**Зачем.** Рекламный бюджет и 30к$ на отделы продаж и Google теперь у владельца — «если докажет свою эффективность». Я веду воронку от регистрации до оплаты и приношу предложения с расчётом. Для этого нужна одна мера на все каналы: сколько стоили регистрация, лицензия, первый сигнал и платящий на каждый потраченный доллар.

**Что уже есть в «Продажах по каналам».** Воронка по коду, период по дате каждой ступени, отбор технических клиентов, «Скачать свод» в CSV, страница канала с графиком. Этого хватает, чтобы считать руками; не хватает четырёх вещей ниже.

**Вопросы**

1. **Расход.** Можно ли хранить рядом с кодом сумму расхода и дату выхода размещения (несколько записей на один код) и считать $ за каждую ступень? Если в этой базе расход держать нельзя — где его держать, чтобы страница могла поделить? Для Google расход уже есть в статистике рекламы — можно ли подтянуть его в строку Google?
2. **Площадка.** Можно ли объединять коды одной площадки в одну строку — ADHUNT + ADHUNT1, CPAGRAM + CPAGRAM1, AFFINSIDE + AFF_INSIDE, IGAMINGNEWS + IGAMING_NEWS — через partner_id у промокода или новым полем? Сейчас «Канал» берёт только один код: при двух кодах в запросе остаётся первый. И коды без регистраций (например SBC_LISBON) в список «Канал» не попадают — их видно только в своде.
3. **Контрагенты.** «Технический» сейчас — только наши прогоны. Можно ли так же отмечать клиентов-контрагентов: площадку или блогера, зарегистрированных по своему коду, наших сотрудников? Кто ставит отметку?
4. **Тип канала.** Можно ли повесить на код тег — пост TG, листинг, блогер, Google, отдел продаж, конференция — и дать итог по типу?
