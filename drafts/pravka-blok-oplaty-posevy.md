# Правка блока «Бюджет и оплата» — четыре задачи посевов

⚠️ Вносится ТОЛЬКО после «да» шефа на рамку (см. `prosba-shefu-ramka-posevy.md`).
До решения блок не трогаем — иначе получится, что аппрув проставили сами себе.

Задачи: CONTENT-61, CONTENT-63, CONTENT-64, CONTENT-65.

**Было:**

```
Бюджет и оплата:
[ ] Аппрув суммы @vladimir
[ ] Взято в оплату @Kit
[ ] Оплачено
[ ] Чек приложен
```

**Стало:**

```
Бюджет и оплата:
[x] Сумма внутри согласованного мешка посевов (CONTENT-4, $6 281, аппрув
    владельца): цена за выход не выше согласованной — отдельный аппрув не нужен
    по рамке от [дата решения]
[ ] Реф-код заведён в кабинете
[ ] Взято в оплату @Kit
[ ] Оплачено
[ ] Чек приложен
[ ] Строка в ведомость месяца MARKETING-104 в день оплаты
```

Две новые строки — не формальность: код отдельной галочкой, потому что три из
четырёх кодов не заведены при готовых текстах со ссылками на них; строка в
ведомость — потому что на этом держится вся рамка, ради которой аппрув снимаем.
