# Правка блока «Бюджет и оплата» — четыре задачи посевов

Задачи: CONTENT-61, CONTENT-63, CONTENT-64, CONTENT-65.

Каналы взяты из действующего сводного мешка CONTENT-45, деньги у Евгении —
отдельного согласования на каждую строку не нужно. Блок приводится к тому, что
есть на самом деле, и в нём появляются две недостающие галочки.

**Было:**

```
Бюджет и оплата:
[ ] Аппрув суммы @vladimir
[ ] Взято в оплату @Kit
[ ] Оплачено
[ ] Чек приложен
```

**Стало:**

```
Бюджет и оплата:
[x] Канал в согласованном мешке CONTENT-45, цена за выход не выше
    указанной в мешке — отдельный аппрув не требуется
[ ] Реф-код заведён в кабинете
[ ] Оплачено @Evgenia
[ ] Чек приложен
[ ] Строка в ведомость месяца MARKETING-104 в день оплаты
```

Две новые строки не для красоты: три кода из четырёх не заведены при готовых
текстах со ссылками на них, а строка в ведомость — то, чего владельцу не
хватило по отчёту за деньги.
