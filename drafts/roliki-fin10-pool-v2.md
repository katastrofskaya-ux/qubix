# Сценарии ТГ-роликов — пул v2 по вердикту владельца 10–11.09 (26 роликов в съёмку)

Пересборка пула по комментарию админа от 11.09: ролики 11 (постбэки) и 20
(клоака) убраны решениями владельца; добавлены семь новых от реестра козырей
(MARKETING-70 §7в) — после них закрыт каждый козырь первого яруса; ролик 14
пересобран на превосходство; в каждом сценарии дописана строка козыря.
Ролик №1 — эталон в теле задачи (правки эталона — код в кадр, замена
формулы — вносятся в тело отдельно). Итог: 19 прежних + 7 новых = 26.

## Общее для всех роликов (в каждый сценарий не повторяется)

- **Хронометраж** 38–40 сек. **Формат** 16:9 для ТГ-поста, вертикаль
  9:16 — отдельной нарезкой. **Съёмка** — экран продукта на коробке с
  демо-данными, живых клиентских данных в кадре не бывает.
- **Панель снимается в облике рабочего стола** (решение владельца 11.09):
  несколько окон рядом — список в одном, карточка в соседнем, помощник
  третьим. Облик подаётся кадром-фоном, своей темы не несёт.
- **Задача каждого ролика:** первое знакомство холодной аудитории —
  представляет продукт и заканчивается оффером.
- **Титр 2 (представление продукта), у всех одинаковый, дословно, две
  строки:** **Qubix: Свой сервер — своя ракета! 🚀 / Тянет от залива до
  офисного пакета.** (итоговая формула, решение владельца 10.09,
  MARKETING-70 §1). Ставится на блоке 0:04–0:09, нижняя треть.
- **Пэкшот (0:32–0:40), у всех одинаковый:** чистый экран, логотип Qubix,
  титры друг за другом, дословно:
  **30 дней бесплатно, со всеми возможностями. По промокоду [КОД] —
  скидка 50%: её размер фиксируется в момент регистрации и держится год.**
  · **Установки PWA — без счётчика, сколько бы их ни было** ·
  **qubix.pro/?r=[КОД] · промокод [КОД]** · финальная строка — своя у
  каждого ролика. Код площадки подставляется при выпуске.
- **Стоп-лист (общий):** частота обходов Facebook и любые «каждые N
  минут»; названия тарифов; логотипы, интерфейсы и сравнения с другими
  сервисами; реальные домены, суммы клиентов, живые кабинеты; «кабинеты
  не горят». **Подписи кнопок в кадре оператор сверяет с панелью на
  месте** (часть названий в сценариях рабочие, не экранные). **Внутреннее
  имя «Britva» в боковом меню кадрируем** — наружу не выносится.
- **От нас каждому ролику:** доступ к коробке с демо-данными (Анастасия)
  и код площадки для пэкшота. Особый реквизит указан в сценарии.

  Титр 2 (якорь).
- **0:09–0:17 · Механика.** Редактор правила: курсор по условию — расход и
  депозиты в одной строке. Вместо «включить» курсор уходит на соседнюю
  кнопку. Титр: **Черновик гоняется тем же движком, что работает в бою.**
- **0:17–0:25 · Ключевой кадр.** Клик «Сухой прогон» → «Совпало: 3
  объявления», три строки с названиями, плашка «изменений не внесено».

  согласен — галочка, правило активно. Титр: **Сначала показывает, что
  сделает. Потом получает права.**
- **Финальная строка пэкшота:** **Право останавливать — после
  доказательств.**
- **Особый реквизит:** правило-черновик и два сухих прогона с непустым
