# Сценарии ТГ-роликов — полный пул (№2–№21), развёрнуто по эталону

Один мешок — одно согласование: все двадцать сценариев разом (ролик №1
развёрнут в теле CONTENT-46 как эталон формата, он двадцать первый).
Заменяет файл партии 1 — ролики №2–4 включены сюда без изменений по сути.

## Общее для всех роликов (в каждый сценарий не повторяется)

- **Хронометраж** 38–40 сек. **Формат** 16:9 для ТГ-поста, вертикаль
  9:16 — отдельной нарезкой. **Съёмка** — экран продукта на коробке с
  демо-данными, живых клиентских данных в кадре не бывает.
- **Задача каждого ролика:** первое знакомство холодной аудитории —
  представляет продукт и заканчивается оффером.
- **Титр 2 (представление продукта), у всех одинаковый, дословно, две
  строки:** **Qubix: Свой сервер — своя ракета! 🚀 / Тянет от залива до
  офисного пакета.** (итоговая формула, решение владельца 10.09,
  MARKETING-70 §1). Ставится на блоке 0:04–0:09, нижняя треть.
- **Пэкшот (0:32–0:40), у всех одинаковый:** чистый экран, логотип Qubix,
  титры друг за другом, дословно:
  **30 дней бесплатно, со всеми возможностями. По промокоду [КОД] —
  скидка 50%: её размер фиксируется в момент регистрации и держится год.**
  · **Установки PWA — без счётчика, сколько бы их ни было** ·
  **qubix.pro/?r=[КОД] · промокод [КОД]** · финальная строка — своя у
  каждого ролика, указана в сценарии. Код площадки подставляется при
  выпуске.
- **Стоп-лист (общий):** частота обходов Facebook и любые «каждые N
  минут»; названия тарифов; логотипы, интерфейсы и сравнения с другими
  сервисами; реальные домены, суммы клиентов, живые кабинеты; «кабинеты
  не горят».
- **От нас каждому ролику:** доступ к коробке с демо-данными (Анастасия)
  и код площадки для пэкшота. Особый реквизит указан в сценарии.
