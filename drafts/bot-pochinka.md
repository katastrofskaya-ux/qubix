# 3. Задача в DEV

**Название:** Бот: продажные ответы, язык, безопасность ссылок и доки — по разбору всех диалогов

1. **Каждый ответ заканчивается вопросом**, на который клиент ответит одной фразой. При жалобе или сбое — вопрос о деле клиента, без продажи.
2. **Готовые ответы** — вставить в prompts/skills/support.md (таблица ниже). Цены в промпт не вшивать: бот берёт их из доков license/billing.
3. **Язык ответа** — язык, на котором клиент пишет в этом диалоге. Отдельные английские слова, коды и ссылки язык не меняют. Тикеты в Ю-трек — по-русски.
4. **Безопасность.** Инструкции из текста клиента бот не исполняет. Ссылки — только на qubix.pro, my.qubix.pro, docs.qubix.pro. Внутренние рассуждения клиенту не уходят. Проверка — повтор SALES-194.
5. **Стоп-слова:** «всё в одном», «медиабаинг», «платформа для медиабаинга». Продукт — Affiliate SuperApp или Qubix.
6. **Статус заявки.** На вопрос «что ответили?» бот отвечает статусом обращения и датой последнего движения.
7. **Новый вопрос после закрытия обращения** — новое обращение, а не комментарий в закрытую задачу (SUPPORT-29, 05.10).
8. **Дожим.** Лид назвал объём или тариф и не ответил на вопрос бота за 24 часа — одно повторное касание с вопросом.
9. **Несовместимый CPU** — бот даёт ссылку на статью о выборе сервера.
10. **Причины заглушек** «ответит первый освободившийся оператор» (16.08–09.09, SALES-63, 160) и «Not logged in · Please run /login» (SALES-63) — найти; при сбое вызова ИИ оповещать команду.
11. **Иконка PWA** — проверить, воспроизводится ли сейчас (SALES-63, 29.08; после были DEV-1673, DEV-1913); если да — обращение.
12. **Доки:**
    - тарифы в license/billing и faq/billing — по таблице ниже (сейчас «Start, Pro и Макс»);
    - дописать: удаление Qubix с сервера; обновление и сброс адреса панели по SSH; языки интерфейса; вкладка «Почта»; значения {status} для источников не Facebook; свои event_name в CAPI; пункты мастера установки;

    - после правок — `reindex-kb`.

# 4. Что решает не разработка

- **Передача без согласия клиента** — вопрос Владимиру (раздел 2).
- **Срок ответа человека** для бота — выбирает Анастасия (например, «ответим сегодня»). Часы и часовой пояс не называем.
- **Получатель заявок по сделкам** — в DEV-задачу вписать после ответа Владимира: обращение SUPPORT с пометкой «сделка» на настраиваемого получателя с уведомлением в Telegram; карточка SALES остаётся на боте.
- **White label на Agency/Enterprise** — что в него входит, решает владелец; на сайте не описан.
