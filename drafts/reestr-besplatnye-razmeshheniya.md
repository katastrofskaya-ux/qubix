# Реестр бесплатных размещений и дружеских договорённостей

Зачем: договорённости «сделаю бесплатно» живут в личках и умирают там же.
Здесь каждая получает строку; когда доходит до дела — заводится задача
размещения, и строка получает ссылку.

Правило: запись появляется в момент договорённости, а не в момент выхода.
Бесплатное размещение проходит тот же путь, что платное: текст из мешка,
код площадки, проверка точки приземления в день выхода, замер по коду.
Бесплатно - не значит без кода: без кода выход не считается.

| Кто | Площадка / канал | Что делает бесплатно | Что просит взамен | Где договорились (дата) | Код | Статус | Задача |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Коля | уточнить | «всё бесплатно» — со слов Анастасии, 02.09 | уточнить | переписка ТГ | нет | договорённость на словах | нет |
|  |  |  |  |  |  |  |  |

Статусы: договорённость на словах → условия зафиксированы → текст отдан →
вышло → замерено.

Пустые графы заполняет Анастасия по своим перепискам — агент их не видит и
выдумывать не будет.
