# Карта мира Qubix — по MARKETING-97

Основа — утверждённый образ бренда (тело MARKETING-97), пересказ без добавок.
Одна правка помечена отдельно внизу.

## Формула (ядро)

Без имени (где продукт назван рядом):
> Свой сервер — своя ракета! 🚀
> Тянет от залива до офисного пакета.

С именем (якорь для холодной аудитории): те же строки, первой — «Qubix:».

## Объект: один, и это сам сервер

Ракета = сервер. Стартует с Земли (развернул за вечер) → на орбите
раскрывается в автономную космическую станцию (работающий сервер команды).
Отдельной «станции Qubix» в мире нет: Qubix — это то, во что раскрывается
ракета у каждого клиента.

**Героем кадра всегда остаётся станция** (владение и автономность); дроны и
корабли — движение вокруг. Запуск ракеты сам по себе — затёртый знак SaaS,
отстройка не в нём.

## Слои объекта

| Слой | В объекте | В продукте |
| --- | --- | --- |
| Ракета → станция | стартует с Земли, раскрывается на орбите | сервер: развернул за вечер — дом команды |
| Станция | автономна: своя энергия, запасы, экипаж | свой сервер: всё хозяйство по правилам команды |
| Дроны (2 типа) | уходят со станции каждый своим курсом | рабочие = кампании; защитные = автоматика, перехватывает минусовое пока экипаж спит |
| Чужие корабли | патруль кружит — станция прикрылась гладким корпусом, патруль улетает | клоака и белая страница |
| Тессеракт | внутри больше, чем снаружи | весь стек + офисный пакет команды в одной коробке |
| Грани крутятся | меняет форму | отсеки под задачу: правила, скрипты, обработчики на сайтах |
| ИИ внутри | кто крутит грани | сказал словами — получил правило, скрипт, дашборд, кампанию |

## Тессеракт — главный слой, 6 свойств

1. Вместимость: одна коробка вместо десятка сервисов + офисный пакет.
2. Рост без роста: внутреннее прибавляется, коробка та же; объёмы не тарифицируются.
3. Своё пространство: внутри не просматривается; наружу — только выпущенное командой.
4. Место для своего: строит сама команда (отсюда грани и ИИ).
5. Ничего не теряется: креативы переживают бан, данные — окончание подписки (только ответом на возражение).
6. Один вход: одни права на всё, поиск по словам и смыслу.

## Главная мысль

Свой сервер — это не морока, а мощь. Быстрый, потому что свой; защищённый,
потому что свой. Доказательство: «На сервере за $74 отдаёт 2 000 PWA-витрин
в секунду».

## Правила

- Слои («станция», «тессеракт», «дроны») — картинкой и сюжетом, не словом в тексте.
- На мониторах рубки — настоящие экраны продукта (камера в рубку → зум → живой экран).
- Тон: уверенный хозяин; показ вместо обещаний; боль состоянием.
- Без крипто-языка, без исторических отсылок, космос нейтральный; стоп-лист M-70 §10 целиком.
- Facebook — не конкурент: его штормы, патрули, ботов показываем прямо и по имени.
- Образ живёт в рекламе и контенте; документация и поддержка — прямой язык.
- Производство: мир делают разработчики игр; первый шаг — пилот-сцена 15–20 сек.

## Носители

Посты канала (сюжеты) · баннеры (куб-станция с дронами + слоган + оффер) ·
ролики (анимационное начало → рубка → живой экран → финал с пэкшотом) ·
стикерпак (после обкатки) · авторские размещения (картинка + сюжеты).
