# Задача: рассылка про релиз со скидкой 50% — три сегмента

Проект: SALES (исполнение частями: бот - саппорт, личные - Анастасия).
Числа - замер admin.qubix.pro на 07.09.

## Зачем

Релиз 2.4.0 вышел 28.08, скидка 50% решением владельца от 06.09 тает со
временем - это готовый повод дожать тех, кто завис между регистрацией и
лицензией. Таких сейчас **43 из 88 клиентских аккаунтов**, у 22 из них
привязан Telegram - им может написать бот.

## Три сегмента - три исполнителя

**Сегмент А. Зарегистрированные без лицензии - 43 аккаунта (бот).**
Пишет саппорт-бот по tg_id из licensing (22 достижимы сразу; для
остальных - письмо на почту аккаунта, если решим). Смысл: вышел большой
релиз + ваш бесплатный месяц ждёт + скидка 50% фиксируется при активации
и со временем уменьшается.

**Сегмент Б. Личные контакты Анастасии, не зарегистрированные.**
Пишет Анастасия лично. Ссылка обязательно с личным кодом (завести,
предложение: NASTYA, 50% + 30 дней, pwa_team - как у площадок), иначе
этот канал не будет виден в замере.

**Сегмент В. Лиды в обработке у Анастасии (карточки SALES).**
Пишет Анастасия в тех же диалогах, тем же смыслом, без ссылок с новыми
кодами (см. правило атрибуции).

## Правило атрибуции - чтобы канал лида не поехал

1. **У зарегистрированного канал уже записан**: referred_by_code
   проставился при регистрации и лежит в аккаунте. Бот пишет по tg_id -
   ничего дополнительно помечать не нужно.
2. **Зарегистрированным НЕ отправляем ссылок вида qubix.pro/?r=КОД.**
   Перейдёт и заведёт второй аккаунт - канал в замере поедет, а человек
   потеряет историю. В сообщении либо нет ссылки вовсе, либо ссылка на
   кабинет без кода.
3. **Замер самой рассылки - по списку и датам, а не по коду**: фиксируем
   список адресатов и дату; кто из списка взял лицензию или оплатил после
   даты рассылки - конверсия рассылки. Канал лида при этом остаётся
   родным (его исходный код).
4. **Код нужен только сегменту Б** - незарегистрированным, у которых
   канала ещё нет.

## Вопрос разработке (блокирует текст про скидку)

Как существующий аккаунт получает скидку 50: вводом промокода на оплате,
выдачей из админки, или автоматически? Промокод сейчас применяется при
регистрации - для уже зарегистрированных механика не описана. Пока ответа
нет, в тексте скидку обещаем без инструкции «как» - или ждём ответа.
Смежное: recurring_months = 0 у всех кодов - годовая фиксация тоже ждёт
подтверждения.

## Порядок

1. Аппрув текстов владельцем (публичная рассылка + цифра скидки).
2. Ответ дева по механике скидки для существующих аккаунтов.
3. Завести код NASTYA (сегмент Б).
4. Выгрузка списка сегмента А из админки (сделаю по запросу) - список в
   задачу НЕ прикладывать целиком, почты и tg - персональные данные;
   хранить файлом у Kit/саппорта.
5. Отправка: А - бот, Б и В - Анастасия. Дата фиксируется в задаче.
6. Замер через 7 дней: лицензии и оплаты по списку адресатов.
