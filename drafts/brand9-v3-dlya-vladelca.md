# Конструкция работы — v3

v3 заменяет v2 (утверждена 04.09) после решений владельца 22–26.09. Помеченное «предложение» ждёт решения.

## Цель

Платящие клиенты по цене не выше потолка. Тексты, каталоги, закупка, конференции — средства; каждое меряется тем, сколько платящих дало и почём. 26.09 закупка рекламы «в лоб» закрыта; v3 ведёт не от темы к размещению, а к платящему: прогноз до траты, тормоз по деньгам, отчёт числами.

## Правила

1. **По числам.** Прогноз до траты, замер после, одна мера на все месяцы. «решения принимаются по метрикам, не сферического коня в ваккуме, а показатели относительно других у кого закупаем рекламу» (22.09).
2. **Вопросы, аппрувы, объяснения и протоколы — в Ю-треке.** «Для всех вопросов - конечно таска в ютреке. И для порядка и для протокола.» / «Не тг» (18.09).
3. **Сначала вопросы, потом работа.** «первым делом провести интервью и понять что и где надо подсвечивать» (18.09).
4. **Условия подрядчиков меняются только в нашу пользу.** «все правки только через ништяки в нашу сторону» (22.09).

## Кто решает

| Что | Кто |

| Новый вид канала (менеджеры, PPC, CPA-блогеры, статьи) | владелец — один раз, по прогнозу |
| Цены, коды, скидки, подарочный месяц | владелец (BRAND-5) |

| Переговоры и условия подрядчиков | Анастасия; владельцу — итог: что уступили и что получили взамен |
| Остановка траты по стоп-правилу | Анастасия, сразу; в недельном отчёте |
| Личные решения владельца | вне моего бюджета, цены и замера |

## Деньги

1. **Прогноз до оплаты** — в задаче траты: канал, сумма, код, дата выхода, дата замера; сколько ждём регистраций, установок, платящих и почём платящий; что делает подрядчик при недоборе. Без прогноза оплаты нет.
2. **Ведомость.** Оплата прошла — в тот же день строка: дата оплаты · сумма · задача-основание (03.09). Итог месяца — в BRAND-12 тремя строками: закупка трафика, всё остальное, итого (22.09).
3. **Потолок.** KPI — полный CAC ~$1 200 на платящего по всему направлению (MARKETING-38). Каналы меряются только деньгами за трафик (22.09). Потолок цены платящего по каналу — предложение: ⟨число⟩.
4. **Стоп-правила** (предложение; заменяют порог $330 от 04.09):
   - новый канал — первый платёж не больше $1 000, следующий только после замера;
   - общий тормоз — с даты утверждения v3 на трафик потрачено больше двух потолков канала без нового платящего → новые траты стоп до решения владельца в задаче; каталоги, обзоры и статьи — отдельным лимитом;
   - блогеры — только CPA: «Без всяких предоплат. Оплату только по факту оплат нам» (26.09);
   - порог после замера не двигается; пересмотр — до следующей траты.
5. **Продление подрядчика** — только если его метрики не хуже среднего по нашим закупкам, иначе платёж разовый (22.09).

## Ритм (предложение)

- **Каждый день** — список «кому касаться»: у кого подарочный месяц кончается в ближайшие 7 дней, незавершённые оформления, новые лиды.
- **Понедельник — лента недели** в BRAND-12, один комментарий, который правится до конца недели, а не множится: «В работе» (что · до когда · статус), «Нужно ваше решение» (вопрос · задача), «Числа недели» (новые платящие, воронка по источникам, деньги против бюджета, что остановлено).
- **Отдельная задача** — только если нужна оплата, решение владельца, работа другого человека или вопрос эксперту. Остальное — строкой в ленте.
- **Созвон** — повестка = «какие решения нужны» из отчёта; протокол — в ту же задачу: решение · кто · срок.
- **Месяц** — письменный отчёт по договору; бюджет следующего месяца прогнозами.
