## Наш столбец (по BRAND-10)

- «Автоправила ✓✓» — в сноске «725 макросов»; по карте «более 700» (717 на
  стенде 26.08), точное число называть нельзя.
- «Кастомные дашборды ✓» — по карте «Мои дашборды» (свои наборы графиков из
  ответов ассистента, до 100 на дашборд); можно оставить ✓.
- **Строки «Таск-трекер», «Мессенджер команды», «Звонки», «Мобильные
  приложения команды» стоят как ✓✓.** По BRAND-10 (§17) клиентам выпущен только
  Диск с редакторами; задачи, календарь, мессенджер, звонки, базы, почта —
  [не выпущено], на коробке клиента скрыты. В теле нет пометки «строится» у этих строк, а BRAND-15 её требует, и на демо невыпущенное не показываем (решение владельца 26.08).
- «Парсинг FB-статистики без Meta-API» — по карте так писать нельзя:
  транспорт официальный Graph API; допустимая формула — «на сессии кабинета,
  без app review и OAuth».
- «Интеграции источников ~¹⁴» — Google по карте [не выпущено], TikTok [задел];
  в сноске не обещать.

Сноски с суммами (Binom Protect $99, Automizer $375–2 380, RedTrack $79+) — без
