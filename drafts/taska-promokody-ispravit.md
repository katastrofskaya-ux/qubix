# Промокоды каналов: выставить настройки

Проверено руками по админке 23.09.2026. Правим 28 кодов, у всех
`used_count = 0` — правка ни на кого не влияет.

## Целевое состояние

Для всех кодов каналов и партнёров должно стоять:

| Поле | Значение |
|---|---|
| Скидка | **50%** |
| Бонус-дни | **0** |
| Месяцев скидки | **12** |
| Тариф | **любой** |
| Цикл оплаты | **любой** — и месячный, и годовой |
| Лимит применений | **без лимита** |
| Срок действия | **без срока** |
| Статус | **включён** |

«Любой» тариф и «любой» цикл — принципиально: если код заперт на один тариф
или только на месячную оплату, человек, выбравший другое, скидки не получает
вовсе — код просто не принимается.
