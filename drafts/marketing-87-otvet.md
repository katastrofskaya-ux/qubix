## Правила движения

1. **Тема живёт один раз** — в мастере. Месячный план — выборка, не копия:
   выдачи дописываются в строку темы (куда → когда → номер задачи).
2. **Тексты не ждут денег и пишутся под все темы месяца.** Темы
   согласованы — мешок пишется целиком (фикс Жени); первыми — темы с
   назначенными выдачами. Деньги нужны только закупке.
3. **Закупка — после мешка.** Слоты бронируются пакетом «3 поста», когда
   тексты готовы; каждое размещение — подзадача с суммой на одобрение.
   Оплата в тот же день ложится строкой в ведомость месяца.
4. **Плановая частота — 3**: каждая тема трижды, в трёх разных каналах.
   Не у всякой площадки есть три слота — берём сколько даёт, недостающие
   касания добираем другими каналами из мешка. Канал фиксируется при брони.
5. **Один текст → три причёски.** Базовый текст один, адаптация под голос
   канала — после фиксации слота.
6. **Проверка перед сдачей — по названным сводам**: стоп-лист MARKETING-70
   §10, red flags MARKETING-9, факты продукта — только карта MARKETING-3,
   согласованные примеры болей — MARKETING-68; своды агента — MARKETING-86.
   Машинный прогон по этим же источникам → вычитка → владельцу.
7. **Замер и чистка мешка**: после каждого круга — все ступени по каждому
   коду с ценой ступени. Слабость канала определяется порогом числом (ниже);
   слабая заявка сетки — повод для замены.
8. **Точка приземления проверяется глазами в день выхода**: ссылка
   размещения открывается в инкогнито — за ней продающая страница, а не
   голая форма, и код подхватывается. Без этой проверки размещение не
   выходит.

## Порог слабости канала (на утверждение)

Окно замера: 7 дней после выхода (72 часа — ранний сигнал). Канал выводится
из ротации при любом из двух: цена регистрации по кодам канала > $330
(3× плановой $110), ИЛИ при 3+ регистрациях — ноль установок на сервер.
После утверждения порог в спорах не пересматривается на глаз.
