## Атрибуция / реферальная ссылка

- Формат: `https://qubix.pro/?r=КОД` → ставит куку `qubix_ref`
  (Domain=.qubix.pro) → применяется при регистрации
  (`customers.referred_by_code`).
- Коды генерит владелец под системным юзером в кабинете (до 50 кастомных) —
  под каждый канал/размещение свой код = чистая атрибуция по источнику.
