# Возможности продукта — выжимка для копирайтера


**Как читать статусы**: «работает» — можно использовать как факт, показывать
демо. «Строится» — упоминать можно (см. `copywriter-brand-frame.md`, раздел
4, пункт 2), но только с этой пометкой, без обещания сроков, без выдачи за
готовое.

## Работает — можно закрывать как факт

**AI-ассистент**
- AI-чат на каждой странице — спросить про свои данные словами, без
  ручных запросов.
- AI-агент выполняет действия по разговору: завести кампанию, поставить
  объявление на паузу — с подтверждением, случайно не сработает.
- AI сам пишет правило по описанию словами — порог входа нулевой, JS
  знать не нужно.
- AI находит похожие креативы автоматически — сравнить с тем, что уже
  выстрелило.
- AI генерирует push (текст, перевод, баннер, иконку) и отзывы для PWA.
- Подключить свою аналитику/AI к данным Qubix снаружи (программный доступ).

**Автоправила**
- Правила на настоящем JavaScript, а не крутилки-формочки — полная
  свобода логики.
- Правило видит каждый показатель объявления и может запросом достать
  всю статистику продукта.
- Паузы гибко: на уровне объявления/группы/кампании, 7 типов (включая
  «до полуночи по времени гео объявления»).
- Свои автоматизации под любой сценарий — не дожидаясь фич от вендора.

**Трекер и аналитика**
- Один экран — вся юнит-экономика залива.
- Уникальная фишка: подсказывает, когда лить (по часам/дням недели и гео).
- Сверка Facebook vs трекер — ловит недолёт конверсий раньше, чем это
  становится проблемой.
- Выгрузка любого отчёта в CSV.
- Права по ролям — байер видит только своё, тимлид/админ — всё.

**Сбор данных и креативы**
- Сбор статистики из рекламного кабинета работает в фоне — антидетект
  постоянно открытым держать не нужно.
- Одинаковые креативы склеиваются автоматически (не считаются заново).

**Клоака и сплиты**
- 9 типов условий разводки трафика (гео/город/устройство/язык и другие).
- Реальные фильтры: боты, датацентры, VPN/Tor — фильтруются до показа
  оффера.

**PWA-конструктор**
- Свой конструктор витрин, безлимит установок и подписок — в коде нет
  счётчика, который бы это ограничивал.
- Клонировать рабочую PWA — секунды, не с нуля.

**Домены**
- Весь цикл (покупка → зона → готово к работе) — автоматически.
- Мониторинг доменов на антивирусные блокировки с уведомлением, как
  только домен помечен заражённым.

**Push-кампании**
- Догнать «зарегался, но не внёс депозит» через нужное время, в удобный
  для подписчика локальный час.
- AI-перевод кампании на нужные языки.

**Уведомления**
- Разносить события по отдельным Telegram-каналам (депозиты отдельно от
  аварий) — не тонуть в общем потоке.

**Права доступа (RBAC)**
- Гибкая матрица прав по разделам продукта — тимлид видит финансы, байер
  — только свои кампании.

**Постбэки и партнёрки**
- 328+ готовых шаблонов интеграций с партнёрками — подключить в пару
  кликов, не разбирая документацию каждой сети вручную (пиши с плюсом,
  число живое и меняется от выпуска к выпуску).
- Приём постбэка не завязан на формат конкретного трекера — переносить
  можно без переписки правил в каждой партнёрке отдельно (см. оговорку
  про миграцию ниже — это не значит «миграция не нужна»).

**Диск и документы**
- Общий диск, точечный доступ по ролям (читатель/комментатор/редактор),
  доступ по ссылке — с паролем и сроком жизни при необходимости.
- Документы и таблицы редактируются прямо в браузере, совместно и в
  реальном времени, с комментариями к конкретному месту в тексте.

**Разграничение по тарифу**
- Теперь реально работает (раньше было ограничение только на словах) —
  можно честно говорить «в тарифе X это есть, в Y — нет».
- ⚠️ **Не все возможности выше одинаковы на любом тарифе линейки —
  проверено по MARKETING-5 (24.08.2026), источник истины по тарифам.**
  Конкретные гейты (одинаково для обеих линеек, считая по номеру ступени —
  для Tracker и PWA названия ступеней на этом номере разные, см.
  `resource-map.md`): JS-автоправила, FB-парсер, CAPI, AI-разметка
  креативов — со **2-й ступени** (Tracker Pro / PWA Starter), на 1-й
  ступени (Starter/Lite) их нет. Серверные скрипты по расписанию и
  API-доступ для AI — с **3-й ступени** (Tracker Team / PWA Pro).
  White-label — с **4-й ступени** (Agency). На 1-й ступени входит: трекер и
  воронка, AI-ассистент, клоака/сплиты/домены, командные роли, безлимит
  трафика. Не говорить «автоправила и AI работают одинаково на любом
  тарифе» — это неточно.

## Строится — упоминать только с пометкой «строится», без сроков

Мессенджер (чаты, реакции, поиск, звонки с демонстрацией экрана,
транскрипция), Задачи (канбан, @-упоминания), Календарь (командный,
повторяющиеся события), мобильные приложения iOS/Android, умные таблицы
и групповые звонки.

## Важные оговорки — чтобы не соврать по правилу «правда = продукт»

- **«100% долёт конверсий» (CAPI)** — это формулировка лендинга про
  серверную природу отправки (нет потерь от блокировок в браузере), не
  измеренный факт долёта. В тексте — про надёжность механизма, не
  дословный процент.
- **«Более 700 макросов»** — говорить «более 700», не точное число: оно
  живое и зависит от версии продукта у конкретного клиента.
- **Обратная отправка конверсий в рекламную площадку** — сегодня сделана
  для Facebook. По остальным площадкам работают только приём и разметка
  кликов — не обещать то же самое для них.
- **Приём постбэков «в любом формате» — это НЕ отсутствие миграции.**
  Офферы, кампании, PWA, домены и сплиты при переходе всё равно
  настраиваются заново вручную. Продаём не «миграция не нужна», а «первый
  шаг — одна кампания рядом со старым инструментом, без переезда всего
  хозяйства сразу».
- **Историю старого трекера не переносим — не обещать перенос данных.**
  Решение принято на этапе разработки: клики «в полёте» на момент
  переключения теряются сознательно, статистика начинает копиться на
  сервере клиента со дня подключения к Qubix, не раньше.
- **Запись сессий и тепловая карта** — платная функция сверх базового
  тарифа, не включена всем по умолчанию.
- **Графические редакторы** — сейчас не работают (только снятие
  водяного знака с фото; для видео — в статусе беты). Не упоминать
  редакторы как готовую функцию.
- **«До 80 000 запросов/сек»** — формулировка лендинга, не подтверждена
  измерением в карте фичей. Использовать с осторожностью, не как точный
  бенчмарк.
