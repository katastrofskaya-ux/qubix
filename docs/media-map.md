# Медиа-карта и рекламный ландшафт RU-арбитража

Источник: MARKETING-10 (Masha TG-intel, наблюдение 06.2024–06.2026). Куда
нести рекламный бюджет, какими сообщениями, по какой цене, к кому идти за
размещением. Цена входа в рынок: $300–1000 за пост. Вертикаль: FB-медиабаинг,
гемблинг/беттинг.

## Карта рынка

Рынок делится на трекеры (учёт трафика) и PWA-сервисы (приложения-прокладки).
Qubix объединяет оба — конкурирует на двух фронтах сразу.

Две маркетинговые модели: «свой пузырь» (FBM — 97% упоминаний внутри
собственных каналов) против «покупки слотов» (ClickLead, ZM apps, EpicPWA).
**Для входа Qubix органична модель закупки слотов в чужих живых каналах**, а
не строительство своей экосистемы с нуля.

Привратник рынка — **igaming_news**: через него проходит почти вся платная
PWA-реклама; хорошая витрина для мониторинга конкурентов.

## Формат рекламы

- **Нативное видео (15-40 сек)** — топ-формат, 2× охват и 2.6× репостов
  против фото. Без ссылок на YouTube (не даёт охвата, уводит из мессенджера).
  Формат для Qubix: скринкаст продукта (трекер+PWA в одном окне, авто-сборка
  отчёта/связки за 30 сек), без говорящей головы.
- Запасной формат — набор скриншотов-альбом (охват/шеры выше одиночного
  фото, вовлечённость чуть ниже).
- Эмодзи — стандарт рынка (~100% постов). Длина текста — либо минимум на
  сильном визуале, либо предметный лонг 600-1200+ символов; провал у
  коротышей <200.
- Анатомия подписи (6 элементов): хук (эмодзи + сильное заявление) → узнава-
  емость (привязка к знакомому) → что показываем (демо) → выгода для БАЙЕРА
  (ROI-язык) → CTA («запустить демо», «промокод X») → атрибуция (@канал +
  промокод).
- Тон: образовательно-софт-селл или нативная новость — органично для Qubix
  как серьёзного B2B-инструмента. Капс-хайп/мемы (стиль ClickLead) уронит
  доверие к аналитическому продукту.

## ⚠️ Находка по собственному активу: риск ПДн

В ходе медиа-аудита обнаружен собственный технический канал-приёмник заявок
с формы Facebook (не маркетинговый канал), где в постах лежат имя+телефон
лида (~204 лида). Внешний индексатор извлёк ~196 телефонов в поисковый
индекс — риск по 152-ФЗ/GDPR. **Требует эскалации команде**: чей канал,
закрыть внешний доступ, вычистить индекс, разобраться с бот-флудом по форме.
Не маркетинговая задача, но не тянуть — см. `CLAUDE.md` раздел «Известные
открытые риски».
