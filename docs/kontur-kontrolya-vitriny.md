Создан 03.09.2026 после прецедента: платный трафик первой волны приземлялся
на голое окно регистрации (продающей страницы за ссылкой не было), ТГ-канал
до 03.09 стоял пустым. Урок: мы проверяли ССЫЛКИ, но не проверяли, ЧТО ВИДИТ
человек за ними. Этот файл — чтобы такое не повторилось.

## Правило № 1 (в конструкцию, правило 8)

**Ни одно платное размещение не выходит, пока точка приземления не проверена
глазами в день выхода**: открыть ссылку поста в инкогнито → увидеть то, что
обещает пост → дойти до регистрации → убедиться, что код подхватился.
Проверка занимает две минуты и стоит дешевле любого слитого поста.

## Еженедельная «прогулка по витрине» — 5 минут руками

Из окружения агента qubix.pro и my.qubix.pro закрыты сетевой политикой —
поэтому раз в неделю (например, понедельник, до брони слотов) руками:

1. Инкогнито → `qubix.pro/?r=TEST100` → лендинг? регистрация с кодом?
2. Канал: последний пост когда? закреп стоит?
3. Бот: /start с чужого аккаунта — отвечает?
4. Сайт: заголовок = текущее позиционирование?
5. Одна случайная карточка листинга: текст/код/лого наши?

⚠️ Тесты — только в инкогнито: в рабочем браузере сидит кука qubix_ref=IVANOV.

## Что контролируется автоматически (уже стоит)

- **Ежедневно, 08:00 МСК** — прогулка Маши: упоминания Qubix, посты с нашими
  ссылками (видно, какая форма ссылки реально вышла в поле!), пульс
  конкурентов.
- **Ежечасно 08–23 МСК** — новые лиды и обращения.
- **17:00 МСК** — дедлайны завтрашнего дня.
- **09.09** — разовый замер первых посевов.

## Что добавить в автоматику (нужно одно действие Анастасии)

Завести в Settings → Secrets окружения переменную `ADMIN_QUBIX_COOKIE`
(значение — кука админки, сейчас лежит только в scratchpad сессии). Тогда:
- в утренний разбор добавится блок «регистрации за сутки по кодам + движение
  по ступеням (регистрация → лицензия → установка → оплата)» — живой счёт
  каждый день, а не по запросу;
- истекающие бесплатные периоды будут подниматься сами за 3 дня до конца.

## Расширить сетевую политику (по желанию, тоже действие Анастасии)

Добавить в политику окружения `qubix.pro` и `my.qubix.pro` (как уже добавлены
admin/docs) — тогда агент сможет сам раз в день проверять, что лендинг жив,
отдаёт новое позиционирование и не сломан редирект с `?r=` — и «прогулка по
витрине» из ручной станет автоматической.
