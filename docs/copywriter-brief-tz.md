## 2. Медиаплан — платные размещения в Telegram (T1, приоритет)

Из `docs/media-map.md`, канонический источник форматов и приоритета.
Обязательно (T1): **cparip, igaming_news, .Aff Inside, adhunt,
MoneyBeatsEvil**.

**Формат**: нативное видео-демо 15-40 сек (не скринкаст с говорящей головой,
без ссылок на YouTube — уводит из мессенджера, режет охват). Запасной
формат — альбом скриншотов.

**Анатомия подписи (6 элементов, обязательная структура)**:
1. Хук (эмодзи + сильное заявление)
2. Узнаваемость (привязка к знакомой боли/ситуации байера)
3. Что показываем (демо/визуал)
4. Выгода для байера (ROI-язык, не фичи)
5. CTA («запустить демо», промокод)
6. Атрибуция (@канал + реф-код)

**Тон**: образовательно-софт-селл или нативная новость — НЕ капс-хайп/мемы
(стиль ClickLead уронит доверие к аналитическому B2B-продукту). Эмодзи —
варьированные, не монотонные. Длина подписи — либо минимум при сильном
визуале, либо предметный лонг 600-1200+ символов; короткие (<200 символов)
проваливаются по вовлечённости.

Каждый канал — свой реф-код для атрибуции (правило уже принято командой).
