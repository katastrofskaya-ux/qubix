# Решения владельца 25–26.08.2026 — что изменилось в правилах

Зафиксировано по обновлениям MARKETING-70, 68, 9, 5, 3 и CONTENT-11, 6.

## 1. Как выбирается тема материала

**Было:** тему даёт боль — идём по карте болей сверху вниз.

**Стало:** **тему ведёт козырь, боль — повод о нём заговорить.**

⚠️ Формулировка менялась дважды за сутки. 25.08 было «боль — дверь», 26.08
этот оборот **убран отовсюду** — из MARKETING-70, MARKETING-9 и CONTENT-11.
Если он остался в черновиках или брифах, заменить.

Причина решения названа прямо: контент-план из десяти тем, где все десять —
боли, читается как реклама обычного трекера. Каждый пост по правилам, а
серия не продаёт ничего нашего.

## 2. Реестр возможностей по трём ярусам (MARKETING-70, раздел 7в)

| Ярус | Что это | Ведёт ли тему |
|---|---|---|
| 1 — козыри | нет ни у кого | да, первый выбор |
| 2 — преимущества | есть у других, у нас сильнее | да, но только через превосходство |
| 3 — гигиена | уровень рынка | нет, только строка в обзорах |

**Ярус 1 — 16 позиций:** ассистент в продукте · Claude на всю команду одной
подпиской · офис команды на сервере залива · автоматизация на настоящем
JavaScript с сухим прогоном · аналитика вопросом · кросс-кабинетный счёт
креативов · запись сессии рядом с воронкой · MCP в обе стороны · сбор через
свой антидетект · постбэки в формате любого трекера · сайты с серверным
кодом · домен полным циклом · права на всё хозяйство разом · чистка
комментариев с журналом · безлимит установок по подписке · **витрина PWA**.

**Витрина PWA переехала из яруса 2 в ярус 1** — решение владельца дословно:
«за счёт того, что у нас безлимитные инсталы» и «у всех конкурентов плата за
инстал». Ярус 2 теперь начинается с пушей.

**Ярус 2:** пуши, серверная отправка с добиванием, хранение креативов,
гео-скоринг, воронка дальше депозита, медиа-инструменты, один сервер тянет
всё, кошельки, клоака. Отдельно «данные переживают подписку» — **только как
ответ на возражение**, сценарий ухода не продаём.

Статусы выпуска перед каждым материалом сверяются с картой возможностей
MARKETING-3 (теперь 18 блоков).

## 3. Раздача тем по каналам (MARKETING-70, раздел 11)

**Отменено:** формула «дороже показ — выше тема по пулу» и «только
флагманские темы из головы пула». Дословно: «мы количество и качество
смешиваем».

**Стало:** тема раздаётся **по считываемости козыря**.

| Канал | Что даём |
|---|---|
| Крупный | козырь, который считывает вся холодная аудитория без знакомства с продуктом |
| Нишевый | козырь точно под нишу канала, с глубиной |

Нишевый канал остаётся полигоном обкатки.

## 4. Tone of voice — три правки (MARKETING-9)

**Раздел 1.** «Benefits sell, features tell» — правило про **подачу** (в
готовом тексте боль стоит раньше возможности), а не про **выбор темы**. Это
снимает самое частое неверное чтение.

**Раздел 8, новый red flag:** тема существует только из-за боли. Проверка —
**закрыть название Qubix: если текст может выпустить любой трекер, козыря
нет, тема не готова.**

**Раздел 9, процесс.** Порядок шагов изменён:

1. назови козырь
2. подбери боль-повод
3. назови показ — что читатель увидит работающим
4. прогон по Red flags

## 5. Early Bird — окончательные условия (MARKETING-5)

Проверено по влитому коду (DEV-1883):

- **Календарного окна нет.** Срок «по 31 августа» убран, подарок сам не гаснет.
- **Промокод не нужен.** Месяц получает любой зарегистрировавшийся.
- **Выключатель ручной.** Акцию гасит оператор одной настройкой, без публичной даты.
- Тариф подарка — средняя ступень линейки витрин, **в текстах ступень не называем**: «30 дней бесплатно, со всеми возможностями».

**Для текстов:** оффер ставится без оговорок про промокод и без сроков.
Реф-ссылки и коды остаются в постах **только ради атрибуции канала** — на
выдачу подарка они больше не влияют.

## 6. Мелкое

**MARKETING-68**, боль 4: «трафик переводится долей в сплите» уточнено до
«в сплите **Qubix**» — без уточнения фраза читается как обещание про систему
читателя, которой мы не знаем.

**CONTENT-11**: добавлены темы 21 и 22 — кросс-кабинетный счёт креативов и
MCP (козыри 6 и 8, прежде тем не имевшие), обе нишевые, в хвосте пула. Из
формулировки «пул из 20 тем» убрано число: перечень тем и есть пул. Тема 3
(витрина PWA) подтверждена во флагманской тройке окончательно.
