## Правила движения

1. **Тема живёт один раз** — в мастере. Месячный план — выборка, не копия:
   выдачи дописываются в строку темы (куда → когда → номер задачи).
2. **Тексты не ждут денег и пишутся под все темы месяца.** Темы согласованы —
   мешок пишется целиком (фикс Жени); первыми — темы с назначенными выдачами.
   Деньги нужны только закупке.
3. **Закупка — после мешка.** Слоты бронируются пакетом «3 поста», когда
   тексты готовы; каждое размещение — подзадача с суммой на одобрение.
   Оплата в тот же день ложится строкой в ведомость месяца (этаж 4).
4. **Плановая частота — 3**: каждая тема трижды, в трёх разных каналах.
   Но это план, а не догма: не у всякой площадки есть три слота или пакет —
   берём сколько даёт, недостающие касания добираем другими каналами из
   мешка. Канал фиксируется при брони, до того — ориентир.
5. **Один текст → три причёски.** Базовый текст один, адаптация под голос
   канала — после фиксации слота.
6. **Проверка перед сдачей — по названным сводам**: стоп-лист MARKETING-70
   §10, red flags MARKETING-9, факты продукта — только карта MARKETING-3,
   согласованные примеры болей — MARKETING-68; своды агента — MARKETING-86.
   Машинный прогон `scripts/check-copy.py` — по этим же источникам; затем
   наша вычитка, затем шефу.
7. **Замер и чистка мешка**: после каждого круга — все ступени по каждому
   коду (регистрация/лицензия/установка/покупка) с ценой ступени. Слабость
   канала определяется порогом числом (ниже), а не на глаз; слабая заявка
   сетки — повод для замены.

пишется сюда как правило и в спорах не пересматривается на глаз.
