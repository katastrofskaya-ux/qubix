# Календарь профильных конференций (affiliate / iGaming / CPA)

Даты проверены веб-поиском в июле 2026 (не из памяти модели) — актуальность
на момент проверки; **перепроверять перед бронированием**, так как
мероприятия могут сдвигаться. Приоритизация — под вертикаль gambling/betting
и аудиторию FB-медиабайеров.

## Рекомендация по формату

Не пытаться закрыть всё — при $49-500 продукте и только запустившемся
бренде важнее физическое присутствие с чётким posture («мы только вышли,
демо, Early Bird») на 2-3 событиях, чем размазанность по шести. Предлагаемый
костяк: Ace Alliance Riga (август, разогрев) + Affiliate World Cancun
(сентябрь, главный выстрел) + CIS-мероприятия в Москве по мере готовности
материалов.

## Операционное напоминание (см. также CLAUDE.md)

Любая поездка требует предварительного письменного одобрения компании
(цель/бюджет/длительность) — см. `contract-and-nda-summary.md`. Учитывать
визовые сроки заранее (миграционный статус — личная ответственность
консультанта по договору).
